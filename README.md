Python Operator Overloading

A beginner-friendly Python project demonstrating operator overloading using Python's special (dunder) methods.

📌 About the Project

This project demonstrates how Python allows objects of a custom class to work with operators such as "+" by defining special methods like "__add__()".

🛠️ Concepts Covered

- Python Classes & Objects
- Operator Overloading
- Dunder Methods
- "__add__()" method
- Basic Object-Oriented Programming

💻 Technologies

- Python

🚀 How to Run

1. Clone the repository.
2. Open the Python file in your preferred code editor.
3. Run the program using Python.

python filename.py

🎯 Learning Objective

The goal of this project is to understand how operator overloading works in Python and how special methods can customize the behavior of operators for user-defined objects.
